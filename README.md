# 🤖 EVE Store Bot — بوت متجر تيليجرام متكامل

بوت تيليجرام لمتجر رقمي بالنقاط: متجر مفاتيح + رتب + مكافآت + ألعاب + Giveaway
+ نجوم تيليجرام + دعم فني + إدارة قنوات + حماية ذكية + نسخ احتياطي تلقائي.

> 📘 لفهم كل ملف وكل ميزة بالتفصيل: راجع **[PROJECT_MAP.md](PROJECT_MAP.md)**

---

## ⚡ التشغيل السريع

```bash
# 1) بيئة افتراضية
python3 -m venv .venv
source .venv/bin/activate

# 2) المتطلبات
pip install -r requirements.txt

# 3) متغيرات البيئة
cp .env.example .env     # ثم عدّل القيم
export API_TOKEN="123456:ABC..."
export DATABASE_URL="postgresql://user:pass@host:5432/dbname"

# 4) التشغيل
python bot.py
```

---

## 🔑 متغيرات البيئة

| المتغير | إلزامي | الوصف |
|---|---|---|
| `API_TOKEN` | ✅ | توكن البوت من @BotFather |
| `DATABASE_URL` | ✅ | رابط PostgreSQL (يقبل SQLite للتجارب) |
| `ADMIN_PRIMARY` | ➖ | معرّف الأدمن الأساسي (افتراضي مضبوط في الكود) |
| `ADMIN_SECONDARY` | ➖ | معرّف الأدمن الثانوي |
| `CHANNEL_ID` | ➖ | معرّف القناة الافتراضية |
| `CHANNEL_LINK` | ➖ | رابط القناة الافتراضية |
| `LOG_LEVEL` | ➖ | مستوى السجلات: DEBUG / INFO (افتراضي) / WARNING |

## 🧱 بنية المشروع

| الملف | الدور |
|---|---|
| `bot.py` | النواة: الأوامر + راوتر النصوص + راوتر الأزرار + لوحة الأدمن |
| `config.py` | التوكن، الأدمن، القناة، الرتب، وكل الترجمات (5 لغات) |
| `database.py` | PostgreSQL + ملفات JSON + دوال المستخدمين والرتب والمهام |
| `utils.py` | سبام، كابتشا، اشتراك إجباري، عروض خاطفة، النشر متعدد القنوات |
| `keyboards.py` | كل لوحات الأزرار (مستخدم + أدمن) |
| `shop_ui.py` | ترجمات واجهة المتجر |
| `bot2.py` | VIP + Giveaway (5 أنواع) + التجديد التلقائي + الدفع بالنجوم |
| `bot3.py` | معالج الشراء المضمون + مكافحة الاستغلال |
| `bot4.py` | الألعاب المصغّرة (RPS / XO / صيد) |
| `bot5.py` | جسر النسخ الاحتياطي إلى PostgreSQL كل 4 ثوانٍ |
| `bot6.py` | ألعاب القناة التفاعلية (تفاعلات + سباق تعليقات) |
| `bot7.py` | التحكم الشامل بالأعضاء |
| `bot8.py` | الحماية الذكية + الأمر السري |
| `bot9.py` | نظام النجوم `/stars` + العجلة + الصندوق + الاسترجاع |
| `bot10.py` | الطبقة الجمالية Premium + `/pp` |
| `bot11.py` | إصلاحات جوهرية: `/cancel` العام + تنقّل موحّد + فحوصات أمان |
| `bot12.py` | تجربة المستخدم: بطاقة العضوية + الشارات + المتصدرون + تأكيد الشراء + تنبيه المخزون |
| `bot13.py` | مركز قيادة الأدمن: `/dash` + بحث شامل + سجل تدقيق + إذاعة مستهدفة + CSV |
| `botlog.py` | سجلات مركزية + درع معالجات + تنبيه الأدمن عند أي خطأ |

## ☁️ النشر (Railway)

- أضف `API_TOKEN` و `DATABASE_URL` في متغيرات البيئة.
- ملفات JSON محمية تلقائياً عبر `bot5.py` (نسخ احتياطي داخل PostgreSQL)،
  لذا لا تُفقد بيانات المتجر والمفاتيح عند إعادة النشر.
